# 🧠 IsoBrain - Ultra-lightweight Local AI Agent

> **100% Offline - Zero API Cost - Super Fast - Cross-platform**

**IsoBrain** là một AI Agent cá nhân chạy trực tiếp trên máy tính cá nhân. Xử lý ngôn ngữ tự nhiên thông minh, thao tác file và tự động hóa công việc Office mà **KHÔNG CẦN LLM nặng nề, KHÔNG cần GPU và KHÔNG gửi dữ liệu ra ngoài**.

---

## ✨ Tính Năng Nổi Bật

- 🛡️ **Bảo mật tuyệt đối:** Hoạt động 100% Offline, dữ liệu hoàn toàn cá nhân.
- 🚀 **Siêu nhẹ & Tốc độ cao:** Phản hồi dưới 10ms, không tốn RAM/GPU.
- 📁 **Thao tác File/Folder linh hoạt:** Tạo file, tạo thư mục, đổi tên hàng loạt ở bất kỳ đường dẫn nào (`C:\`, `D:\`,...).
- 📄 **Tự động hóa Word:** Đổi font chữ, tìm & thay thế văn bản hàng loạt, xuất Word sang PDF offline.
- 📊 **Tự động hóa Excel:** Tính Tổng (SUM), Trung bình (AVG), Max, Min cột dữ liệu tức thì.
- 💡 **Giao diện CLI Thông minh:** Hỗ trợ gợi ý chữ mờ (Ghost text) và Auto-complete như GitHub Copilot.
